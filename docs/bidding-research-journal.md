# 出价实验演进与问题解决记录

本项目研究预测失准和延迟回传下的预算 / CPA 约束出价。最重要的演进是逐步分开三个问题：过去发生了多少转化、未来候选动作会产生什么响应、控制器如何使用预测。每一层都需要自己的对照和验收条件。

首次整理日期为 2026-11-19。本页依据已经保存的协议、结果和审计重建研究过程；E01–E17 是阅读索引，不代表十七次按顺序发生的独立实验。E15–E17 分别记录同一专家选择研究的设计、工程审查和停止决策。并行诊断和独立分支保留各自身份。实验内冻结的时点按原记录陈述；没有可靠逐日记录的阶段不补写日期。“思考与取舍”是本次事后归纳，实验前判断在对应条目单独标明。

## 建立评测并检验初始假设

### E01 小规模试验暴露稀疏转化与硬筛选问题

- **问题与原判断：**先检查数据、训练、执行、结算和报告能否完整运行，并观察稀疏转化下的决策行为。此时尚无有效性结论。
- **方案与对照：**4 / 2 / 4 个训练 / 验证 / 开发评估市场，3 个广告主，1 个训练种子；DT 与 response 各训练 1,500 步。比较固定乘数、反馈和学习策略。
- **观察结果：**480 条周期评估记录；固定乘数有竞争力，硬筛预测 CPA 可能抑制消耗，历史修正没有稳定优势。完整运行约 183 秒。
- **处理决定：**正式研究采用带 CPA 惩罚的软目标，保留硬筛选消融；正式测试市场与看过的 pilot 市场分离。
- **思考与取舍：**稀疏转化下，预测 CPA 的硬条件可能把不确定性变成拒绝投放。先检查转化量、消耗与结算语义，再扩大样本，有助于避免放大设计问题。pilot 的作用是改变实验设计。

证据：[信息边界与 pilot 后设计调整](bidding-protocol.md)；[pilot 原始记录](../reports/bidding-pilot/results.csv)。

### E02 正式实验区分失败主假设与探索性发现

- **问题与事前假设：**历史反馈比例修正能否改善响应模型的约束决策？冻结主比较为高估 50% 下 `response + correction` 对原 `response`。
- **方案与对照：**16 / 6 / 12 个训练 / 验证 / 测试市场，3 个训练种子，5 个压力场景，6,480 条记录。校正复用同一检查点，参数只在验证市场选择。
- **观察结果：**主比较 score 差 −0.577，市场聚类 95% 区间 [−1.275, 0.095]；转化差 −0.463；违约频率下降 2.78 个百分点，但平均 CPA 债务从 243.21 升至 270.91。三个种子的 score 差均为负。
- **处理决定：**保留主假设未获支持的结论。原 response 相对 feedback 在高估 50% 下的 score +18.3% 另列为探索性信号，交给新研究确认；同时保留名义和低估场景的退化。
- **思考与取舍：**少违约、少转化和更大的违约幅度可以同时发生。单看违约频率会遗漏代价；发现另一个有效比较后，也应保留最初检验的问题。

证据：[正式结果与全部场景](bidding-findings.md)；[冻结主比较](bidding-protocol.md)；[配对统计](../reports/bidding-main/summary.json)。

### E03 同检查点控制实验避免把问题全部归给模型

- **问题与事前假设：**逐时段双价格控制是否比整段恒定动作预测更能利用响应模型？该协议在读取首轮正式测试结果前指定。
- **方案与对照：**复用三个 response 检查点，在六个验证市场比较预算 / 质量价格、累计 / 折扣校正、经验响应，以及完整简单策略网格，共 11,340 条候选记录。
- **观察结果：**选中控制器五场景平均 score 为 6.392，简单参考 15.574、原 response 15.385；违约频率 95.93%。候选未通过晋级门。
- **处理决定：**停止该控制器候选，未生成或查看预留确认市场。没有通过继续训练模型或换测试口径挽救这次比较。
- **思考与取舍：**固定预测器后改变控制器，可以检验这套决策规则的价值。它支持拒绝当前参数范围和实现，不足以否定整个逐时段控制方向。

证据：[控制设计与候选边界](bidding-control-protocol.md)；[选择及失败门槛](../reports/bidding-control/selection.json)。

## 从误差诊断走向独立确认

### E04 同轨迹预测诊断检查损失函数与决策量

- **问题与指定时点：**神经预测器的误差较小，是否意味着控制器需要的成本 / 转化总量准确？context 诊断在正式训练期间指定；matched forecast 扩展在读过 ridge 验证摘要后、读取正式测试结果前指定。
- **方案与对照：**相同的 360 条名义验证行为轨迹、17,280 行；比较神经模型、接收同一当前状态的上下文 ridge、训练集经验曲线。ridge 的当前状态包含历史摘要。
- **观察结果：**经验曲线的当前响应 log MSE 为 0.8053、当前转化总量比 1.043；神经 seed 11 对应为 0.2609、0.841。较低变换误差与转化总量低估并存。
- **处理决定：**把 log 损失、成本 / 转化总量比和策略收益分开报告；这些经过验证集选择的结果保持诊断身份。
- **思考与取舍：**`log1p` 空间的平方损失最优值经反变换后通常不等于条件算术均值；神经 Smooth L1 也没有均值保证。该数学事实提示目标失配的可能性，不能单独确定已训练模型的误差成因。

证据：[诊断时点与数学说明](bidding-context-protocol.md)；[同口径预测报告](../reports/bidding-forecast/report.html)。

### E05 访问轨迹审计发现预算节奏与误差口径差异

- **问题与时点：**main / control 结果出来后，检查失败策略实际选了什么动作、何时花钱。此项是明确的事后诊断。
- **方案与对照：**只重放冻结的 response 和已选 paced 策略，不训练、不选参；1,080 个周期、51,840 个时段，逐周期核对原评估。
- **观察结果：**全部周期精确重放。首时段预算利用率为 response 2.8%、paced 43.8%；所选动作当前转化预测总量比分别为 0.680、1.997。paced 的零动作占 53.2%，全时段误差可能被大量零动作稀释。
- **处理决定：**同时检查所选动作、活跃时段、预算曲线和终局指标；保持失败控制器关闭。
- **思考与取舍：**策略会改变访问状态与后续样本。不同策略轨迹上的误差差异只能提供机制线索；这些数字没有识别唯一因果瓶颈。

证据：[事后审计口径](bidding-onpolicy-protocol.md)；[重放与行为报告](../reports/bidding-onpolicy/report.html)。

### E06 新市场确认只升级原来那条局部发现

- **问题与冻结时点：**原 response 在严重高估时的探索性优势，能否在未见市场重现？新主比较在发现之后、新市场生成之前冻结。
- **方案与对照：**24 个新市场、三个冻结检查点、既定 feedback 参数；不重训、不重新调参，4,320 条记录。先封存全部市场，再评估策略。
- **观察结果：**高估 50% 下 score +17.6%，配对均值差 +2.617、95% 区间 [1.801, 3.424]；转化 +8.4%，违约频率 −24.8 个百分点；三个固定模型的 score 差均为正。低估 score −17.3%；名义 −3.8%，差值区间跨零。
- **处理决定：**确认严重高估场景的局部收益；初始历史修正、失败 paced 控制器与低估问题保持各自结论。
- **思考与取舍：**新市场可以检验新冻结的问题。该收益属于点响应模型与其控制器，尚不能归因于随机生成分布、历史序列或架构本身。

证据：[独立确认规则](bidding-confirmation-protocol.md)；[全场景统计](../reports/bidding-confirmation/summary.json)；[适用范围](bidding-findings.md)。

## 对生成式与机制候选逐项验收

### E07 条件 Flow 先检验复现再检验分布增量

- **问题与复核前假设：**动作相关成本 / 转化的联合分布，是否比点预测或仅使用分布均值提供更好的约束决策？控制参数在训练种子复核前固定。
- **方案与对照：**条件 Flow Matching 生成响应；相对控制器做分位筛选和 feedback 回退。对照包括 point、plugin、关闭分位筛选、打乱跨动作样本；复用六个开发市场。
- **观察结果：**seed 11 通过业务门，seed 23 在高估 25% 下 score 仅 +0.82%，未达 +3%。两个已完成种子中，相对 point 的三个主场景 score 比算术均值变化为 −1.32% / −0.97%；相对 plugin 的高估 50% score 为 −4.58% / −5.48%。
- **处理决定：**按停止规则不运行 seed 37；保留低估开发收益 +5.40% / +4.70%，但业务复现和生成式独立增量均未通过。
- **思考与取舍：**能拟合分布、某个场景提高、分位筛选具有额外价值，是三个不同命题。强点预测和均值插件对照决定额外建模成本是否值得投入。

证据：[完整种子结果与对照口径](bidding-generative-findings.md)；[保留停止状态的摘要](../reports/bidding-generative/summary.json)。

### E08 零拟合审计检查目标与实际控制是否错位

- **问题与时点：**生成式复核失败后，检查模型预测的恒定动作尾响应，与一次动作干预后返回反馈的收益是否属于不同目标。
- **方案与对照：**复用 540 个开发前缀，拆开模型预测 M、真实恒定动作比例投影 P、精确预算恒定动作 C、一次干预后回到反馈 F；随后分解即时结算与后续收益。不新增拟合或新市场。
- **观察结果：**P、C、F 的固定门槛均未支持所需联合优势。4,107 个非反馈动作 × 上下文单元中，终局 score 改善为零的 1,391 个单元，895 个源于即时结算相同，496 个源于整数转化相同且处于 CPA 可行平台。
- **处理决定：**保留目标差异这一风险，停止“失败全部来自未来恒定动作假设”或“零收益全部来自后续抵消”的归因。
- **思考与取舍：**先核对标签和控制问题，再追加训练。score 非线性，成本 / 整数转化可以加法分解，score 不能直接套同样分解；hindsight 最优空间也不足以证明可学习性。

证据：[四层诊断与核对残差](bidding-generative-findings.md)；[目标解释](../reports/bidding-generative/horizon-interpretation.json)；[反馈补偿摘要](../reports/bidding-generative/feedback-compensation.json)。

### E09 两条独立消融检验信息价值与反馈组合

- **问题与事前假设：**H1 增加历史已接受曝光的预测概率累计量 E，能否提供新增预测与控制价值？H2 将现有预算 / 质量信号从乘积改成 minimum，能否减少相互放大？两者分别冻结，互不构成晋级链。
- **方案与对照：**H1 在四个训练市场比较 actual / zero / pseudo E，含 360 个干预上下文；H2 在四训练与六已见开发市场比较原 FB、minimum，另保留 P-only / R-only 诊断。
- **观察结果：**H1 的真实 E 控制宏比为 1.0083159，但物理增量 MSE 恶化 2.4775%，未达改善 5% 必要门。H2 的 minimum 开发宏 score 比 0.8135826、低估 score 比 0.5275262，损失明显。
- **处理决定：**关闭两个固定候选；H2 失败后没有把诊断臂改称胜出方案。独立复核完整性 PASS，两个科学门均 FAIL。
- **思考与取舍：**实现正确与假设成立分别验收。新增特征需要信息增量证据，信号组合需要同时检查消耗、转化与风险，少花钱本身不足以完成约束目标。

证据：[两项冻结设计与拒绝依据](bidding-evolution-audits.md)；[结构化摘要](../reports/bidding-evolution/summary.json)。

### E10 动作结构候选先过预测门再消耗策略评估资源

- **问题与事前假设：**把公开 pCVR 与动作区间的乘积显式加入共享解码器，是否改善未来成本 / 转化响应？
- **方案与对照：**同编码器、采样流、损失和各 2,000 次更新，比较原索引结构 I、共享动作头 A、增加乘积特征 P；参数量接近，并冻结预测晋级门。
- **观察结果：**P 相对 A 的未来成本 MSE +1.85%、转化 MSE −1.34%；相对更强的 I 则分别 +3.18%、+1.69%，未达到各至少改善 5% 的必要条件。同物理出价配对诊断对 A 有利、对 I 不利。
- **处理决定：**候选关闭，未运行策略评估。仅挑 P 对 A 的局部诊断会遗漏更强对照。
- **思考与取舍：**结构直觉值得被检验；相近算力、参数量与强对照能帮助判断效果。预测门失败时停止，可以保留资源和确认数据。

证据：[三臂比较与计算边界](bidding-decoder-findings.md)。

## 延迟反馈研究分离估计与控制

### E11 先建立观测契约再决定是否训练新生成器

- **问题与事前假设：**未回传转化容易与概率高估混淆。能否先修复可见反馈，再检查新增分布建模的决策空间？
- **方案与对照：**48 决策时段、48 成熟窗口，决策 t 仅用截至 t−1 的回传；终局等待至 H+W 后结算。成熟训练历史给定延迟 CDF，对照 arrived-only、先验补回、MAP、posterior 和不可部署的 past-outcome 诊断。偏差方向、真实倍率与未回传标签不进入普通策略。
- **观察结果：**六个开发市场共 19,440 条记录；posterior 选择 gain 0.3 / prior 8，score 14.999058，相对 arrived-only +1.294%。past-outcome 相对最强可部署点参考为 −0.143%，动作改变 5.937%，未达 +2% / 10% 投资门。
- **处理决定：**不在该控制器家族内新增神经生成器；冻结五个方法进入轻量估计的独立确认。
- **思考与取舍：**延迟 CDF 来自稳定匹配历史，这个识别假设必须明确。H=W 时没有在决策前成熟的 live cohort，mature-only 实际始终是先验补回。past-outcome 保留同一启发式控制器，其失败只支持本轮资源决定。

证据：[观测边界、估计公式与投资门](bidding-delayed-protocol.md)；[开发选择](../reports/bidding-delayed-feedback/selection.json)。

### E12 独立确认同时报告小收益与实用目标未达

- **问题与事前假设：**开发选定的 posterior 补回能否在新市场改善成熟终局效用，并满足保护条件？实用目标为 score 至少 +3%。
- **方案与对照：**24 个全新市场、19,440 条周期记录，配对市场 bootstrap；七个单侧保护端点使用 Bonferroni 调整。
- **观察结果：**相对 arrived-only，score +1.21%，95% 区间 [+0.41%, +2.05%]；成熟转化 +1.90%，违约 +0.05 个百分点。七个保护端点通过；+3% 实用门未通过。高估长延迟格 score −4.25%、转化 +1.50%、违约 +2.31 个百分点。
- **处理决定：**发布已确认的小幅总体收益与重要失败格；不把七个已声明组别的保护推广到每个压力格。
- **思考与取舍：**统计上支持正向效应、达到实际投入门槛、各子场景受保护，需要分别回答。总体均值与局部损失都影响策略选择。

证据：[确认结果与保护范围](bidding-delayed-findings.md)；[确认统计](../reports/bidding-delayed-feedback/confirmation/summary.json)。

### E13 同轨迹估计审计与控制公式给出不同层面的解释

- **问题与诊断身份：**pending 估计更准，为什么 score 增益仍小且有局部风险？同轨迹审计是描述性诊断；下述控制导数是看过结果后的结构分析。
- **方案与对照：**先精确重放 1,296 条选定策略轨迹，再对相同可见 cohort 应用四个估计器；真值仅用于离线误差和覆盖评分。
- **观察结果：**长延迟 pending MAE 从 arrived-only 的 2.9271 降至 posterior 的 1.2934，下降 55.81%；但相对 MAP 仅下降约 0.12%。posterior 80% 中央区间覆盖 91.71%，不构成精确标称覆盖或 CPA 安全界。
- **结构分析：**固定已观测成本与时间，原控制器的连续目标动作与 `(V+prior)^gain` 成正比。代入 `V=O+lambda*U`，得到 `d log(action)/d lambda = gain*U/(O+lambda*U+prior) >= 0`。补回增多会弱单调地提高出价；裁剪与最近档位投影保持这一顺序。
- **处理决定与思考：**分别验收估计精度与控制效用，进而检验补回强度。公式提供机制方向，策略随后购买的事件和成本也会改变，不能用它解释全部跨策略损失。

证据：[共同轨迹口径与公式边界](bidding-delayed-findings.md)；[离线审计摘要](../reports/bidding-delayed-feedback/offline-pending-audit/summary.json)。

### E14 用简单补回和可观测校准检验控制机制

- **问题与扩展前假设：**补回全部 pending 会减弱保守压力，部分补回或从可见反馈推断的校准，是否能改善权衡？该扩展在首次确认之后提出、在扩展开发运行前冻结。
- **方案与对照：**只用六个旧开发市场，比较两个固定参考、25% / 50% 补回、两个后验门控、四个相对校准与两个绝对校准，共 12 配置、11,664 条记录。晋级要求对更强固定参考 score 至少 +3%，并过转化、风险、过高估各格与市场方向保护。
- **观察结果：**50% 补回相对 arrived-only 的 score +1.5986%、转化 +1.3509%、违约 −0.3086 个百分点；对更强完整补回参考，score 仅 +0.3008%、违约 −1.4403 个百分点。它在 4/6 市场获益并通过其余开发保护，仍未达到必要的 +3%。门控与直接校准均未胜出。
- **处理决定：**全部配置未晋级，selected=null；不追加阈值、不重开旧确认、不开启预留新市场。保留 50% 补回为开发候选。
- **思考与取舍：**“相对原反馈有提升”与“相对最强廉价对照值得增加复杂度”是不同验收。开发集搜索的最优点需要新市场检验；当前不能把 50% 补回写成已修复高估长延迟失败。

证据：[扩展前冻结规则](bidding-delayed-strategy-protocol.md)；[全部 12 配置](bidding-delayed-strategy-findings.md)；[未晋级选择记录](../reports/bidding-delayed-strategy/selection.json)。

## 未知偏差下先检验专家选择空间

### E15 从局部响应收益提出新的可观测决策问题

- **问题与事前假设：**response 在严重高估场景曾有局部确认收益、低估场景退化；不知道真实偏差时，能否用可见反馈判断何时值得使用它？本轮只研究即时反馈，未知延迟不与专家选择同时引入。
- **方案与对照：**先共同执行 16 时段 gain .3 / prior 8 的反馈策略，再选择继续反馈或使用固定 seed-11 response。两条续程继承实际前缀和剩余预算；目标比较包含前缀成本的完整终局 score。预先分配 8 个新训练、6 个新开发及 24 个预留确认市场，开发对照共 24 种方法，包含完整反馈网格、固定乘数、可观测直接校准和不可部署的 hindsight。
- **信息与验收边界：**选择器只接收可见前缀，真实偏差、最终标签和未选续程结果不进入特征；归一化与候选拟合只允许使用训练市场。先要求 hindsight 对最强廉价开发参考至少有 +3% 空间，再考虑拟合选择器。hindsight 只能诊断这对专家和该前缀。
- **思考与取舍：**把“识别偏差类型”改成“预测当前状态下的专家决策优势”，并让直接校准挑战新增模型的必要性；先验收投资空间，可以避免把复杂度本身当作进展。

证据：[事前协议](bidding-expert-selection-protocol.md)；[设计取舍](bidding-expert-decisions.md)。

### E16 输入、克隆、权重和封存先接受工程审查

- **阶段身份：**这是同一研究的工程准备与技术审查，不是三项独立效果实验，也不提供新的算法收益证据。
- **修复与核对：**使用公开 AuctionNet 派生内核生成全新市场；克隆环境保留队列、账本、预算和真实历史，并逐时段对齐原即时反馈执行。三份公开模拟训练的 response checkpoint 转为无 pickle 的 numeric NPZ / JSON，在声明的旧 parity 市场核对预测和动作一致；本轮事前固定 seed 11。
- **封存边界：**审查修复了源码绑定、选择 / 确认封存、结果来源核验及零方差处理。最初数据生成封存保留，最终实验封存绑定修订后的协议和源码；`e61bda8` 在新市场策略结果分析前冻结。输入字节、源文件和权重有各自身份记录，恢复不应绕过它们。
- **处理决定与取舍：**先把新实验身份和可复现推断路径做实，再分析新策略结果。公开源码 checkout 可生成本研究的新市场；权重转换的推断一致不等于承诺完整重跑原始训练。

证据：[工程决策与修订时点](bidding-expert-decisions.md)；[公开来源记录](../reports/bidding-expert-selection/provenance.json)；[源码复现指南](bidding-expert-reproduction.md)。

### E17 强参考下的空间不足触发事前停止

- **方案与数据：**完成 8 个新训练及 6 个新开发市场，共 252 个 campaign 上下文、2,880 行结果；训练保留两条配对续程，开发比较 24 种方法。独立统计单位仍是市场，不是上下文或结果行。
- **观察结果：**最强廉价参考为 `feedback-g0.7-p8`，平均 score 19.41999556；不可部署的 hindsight 为 19.86152488，相对 +2.2736%，探索性市场 bootstrap 95% 区间 [−3.96%, +8.39%]。低估 / 名义 / 高估组相对参考分别为 −0.7185% / +7.5849% / −0.4180%。同一开发集还选择了参考，因此这些区间和分组比较保留探索性身份。
- **强对照与时点线索：**最佳直接校准相对强参考为 −7.17%；full-day response 整体 −8.80%，高估 +8.51%、低估 −27.71%。这些是开发描述，不能新增宣传收益。完整 response 与前缀后 response 的不同表现提示时点可能重要，尚未识别唯一机制。
- **处理决定：**点估计未达预设 +3% headroom，终态为 `STOP_NO_HEADROOM`、`candidate_results=[]`；未训练 ridge，未生成或打开 24 个预留确认市场。保留强简单参考，停止当前专家对 / 前缀身份，不在结果后扩搜阈值或模型。
- **思考与取舍：**停止说明本轮声明的专家选择空间未通过投入门；没有实际检验可学习性，不否定其他专家、时点或重复路由，也不证明生成式胜出。区间上端不构成重开确认的理由。旧 +17.6% 的确认仍只适用于原参考、三个检查点及原协议。

证据：[结果与边界](bidding-expert-findings.md)；[全部开发方法](../reports/bidding-expert-selection/report.md)；[停止状态及统计](../reports/bidding-expert-selection/summary.json)。

## 当前能支撑的结论

| 命题 | 当前判断 | 关键证据 |
| --- | --- | --- |
| 点响应方案在严重 pCVR 高估时有价值 | 在声明的模拟与冻结检查点下获得新市场支持 | E06 |

这条演进展示的核心工作是：定义可观测信息与终局目标，建立强简单对照，拆开预测和决策，保留失败方案的拒绝依据，再用独立市场校验可宣传的效果。各阶段展示的是相应研究产出与判断，个人分工和 AI 辅助开发按实际经历说明。
