# 生成式出价研究地图

## 研究问题

当广告主看到的转化概率失准时，历史反馈能否帮助出价策略在转化与 CPA 约束之间作出更好的取舍？本项目把问题拆成可复核的模拟实验：先检验响应预测和数值控制是否带来稳定价值，再决定是否值得探索语言模型规划。当前证据来自公开模拟器，不能代表线上投放效果。

## 与前沿工作的关系

GRM（[v1](https://arxiv.org/html/2605.27811v1)）预测依赖历史的成本/价值响应曲线及剩余流量，并用解析方法控制单一乘数。本项目独立实现了紧凑响应预测器，在公开 AuctionNet 代码上构造固定对手实验；它既不是完整 GRM 复现，也不是 AuctionNet 官方基准。AIGB-R1（[v2，2026-11-02 更新](https://arxiv.org/html/2607.17281v2)）采用逐周期高层 LLM Planner、低层 Prompt Decision Transformer Executor，并以经验驱动 rollout 和 D-GRPO 后训练。本项目目前没有这些组件，不能称作 AIGB-R1 复现或 LLM 出价 Agent。

## 最新停止结论

未知偏差研究的开发参考为 `feedback-g0.7-p8`。这对专家在共同前缀后的 hindsight score 为 19.8615，强参考为 19.4200，相对 +2.2736%，探索性市场 bootstrap 95% 区间为 [−3.96%, +8.39%]。点估计未达预设 +3% 投入门，因此在训练选择器前停止。该结果只约束这对专家、这个决策时点及本开发分布；没有检验可学习性，也不能否定全部路由方案或证明生成式胜出。新问题须另立协议和市场分配，不能在本轮结果上追加阈值后开启确认。

## 当前可展示的价值

目前可展示的是有边界的模拟结果、工程与研究方法：把信息边界、检查点复用、验证集选择、预算截断反馈处理和独立确认条件写成可审查协议；保留简单基线和负结果；将预测模型与数值控制器分开比较。这些工作能帮助团队判断复杂模型是否值得继续投入、价值来自预测还是控制，以及性能代价和适用边界。不能把这些模拟结果换称已测业务提升。

对外或面试介绍时，应区分原主假设、事后诊断、新市场确认和未来设想。历史修正主假设未获支持；原 response 在严重高估场景的优势得到新市场独立支持，但低估场景仍明显退化。不要把局部模拟结果说成线上收益、稳定泛化、算法领先或已部署能力。语言模型规划仍是假设，需以公平预算和消融检验其在数值核心之外的价值。
