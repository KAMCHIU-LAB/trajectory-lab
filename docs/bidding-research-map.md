# 生成式出价研究地图

## 研究问题

当广告主看到的转化概率失准时，历史反馈能否帮助出价策略在转化与 CPA 约束之间作出更好的取舍？本项目把问题拆成可复核的模拟实验：先检验响应预测和数值控制是否带来稳定价值，再决定是否值得探索语言模型规划。当前证据来自公开模拟器，不能代表线上投放效果。

## 与前沿工作的关系

GRM（[v1](https://arxiv.org/html/2605.27811v1)）预测依赖历史的成本/价值响应曲线及剩余流量，并用解析方法控制单一乘数。本项目独立实现了紧凑响应预测器，在公开 AuctionNet 代码上构造固定对手实验；它既不是完整 GRM 复现，也不是 AuctionNet 官方基准。AIGB-R1（[v2，2026-11-02 更新](https://arxiv.org/html/2607.17281v2)）采用逐周期高层 LLM Planner、低层 Prompt Decision Transformer Executor，并以经验驱动 rollout 和 D-GRPO 后训练。本项目目前没有这些组件，不能称作 AIGB-R1 复现或 LLM 出价 Agent。

| 阶段 | 已实现或已完成 | 当前状态与边界 |
| --- | --- | --- |
| 第一阶段：预测与控制 | DT、响应预测、固定乘数、数值反馈；公开 AuctionNet 自定义固定对手模拟 | 正式实验运行中；小规模 pilot 尚未显示稳定优势，不支持效果或泛化结论。见[实验协议](bidding-protocol.md)。 |
| 第二阶段：控制器诊断 | 已实现相应实验代码：复用响应模型检查点，比较逐时段双价格控制、累计/折扣校正及训练市场拟合的经验响应曲线 | 正式评估待第一阶段完成后进行；按预设验证门槛筛选，通过后才生成 24 个新市场独立确认。见[控制协议](bidding-control-protocol.md)。 |
| 未来方向：语言模型规划 | 尚未实现 | 只有数值核心相对调参基线呈现可测价值后才考虑；届时须在相同调用预算下，对比 LLM 与固定提示、规则策略并做消融。 |

## 当前可展示的价值

目前可展示的是工程与研究方法：把信息边界、检查点复用、验证集选择、预算截断反馈处理和独立确认条件写成可审查协议；保留简单基线和负结果；将预测模型与数值控制器分开比较。这些工作能帮助团队判断复杂模型是否值得继续投入、价值来自预测还是控制，以及性能代价和适用边界。它们是可复核性与实验设计上的价值，不是已测业务提升。

对外或面试介绍时，应把“已完成的 pilot”“正在运行的正式研究”和“未来设想”分开。正式研究尚未给出最终结果；pilot 没有证明学习策略优于简单出价。不要把模拟器结果说成线上收益、稳定泛化、算法领先或已部署能力。语言模型规划仍是假设，需先通过数值核心实验，再以公平预算和消融验证。
